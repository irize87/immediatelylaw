# 자치법규 폴더

이 폴더에 파일을 넣으면 즉시로 시작 시 자동으로 등록되고, 삭제하면 자동 정리됩니다.
(설치본의 실제 경로: `%APPDATA%\immediatelylaw\data\regulations\`)

- 지원 형식: `.hwpx` `.hwp` `.doc` `.docx` `.pdf` `.rtf` `.txt` `.md`
- 법제처 국가법령정보센터에서 내려받은 파일 그대로 인식됩니다.
  (이 폴더의 `2018…평창군위원회…hwpx`가 실제 예시입니다)
- 직접 만들 때 가장 간단한 형식 — 첫 줄 조례명, 그 아래 `제N조(제목) …`:

  ```
 예시 조례
  제1조(목적) 이 조례는 …
  제2조(정의) …
  ```

같은 이름의 파일이 여러 개면 나중에 등록된 파일이 이름 검색의 우선이 됩니다.
