물음 몇 가지

제 복사 내용이 외부로 나가나요?
나가지 않습니다. 클립보드는 이 컴퓨터의 메모리에서 인용 패턴을 읽기만 하고 저장하지 않으며, 조회는 전부 로컬 데이터로 끝납니다. 설정 › API 키에 본인 명의로 발급받은 공공데이터 인증키를 직접 넣어 ‘현행 여부 확인’을 켠 경우에만 그 건에 한해 법제처 API를 호출합니다.
Windows가 “알 수 없는 게시자”라고 해요
상용 코드 서명(Authenticode)을 적용하지 않은 실행 파일이라 SmartScreen이 경고할 수 있습니다. 아래 내려받기 칸에 공개된 SHA-256 해시와 받은 파일이 같은지 확인한 뒤 실행하세요. 소스는 MIT 라이선스로 공개되어 있어 직접 빌드해 쓰는 것도 가능합니다.
어떤 PC에서 되나요?
Windows 10·11 64비트입니다. 관리자 권한이 필요 없고 현재 사용자에만 등록됩니다(HKCU). 디스크는 약 300MB, 설정과 데이터는 사용자 폴더(AppData)에 저장됩니다.
인터넷이 차단된 망에서도 쓰나요?
오프라인 패키지는 최신 데이터가 동봉되어 설치와 실행이 전부 오프라인으로 됩니다. 최신화할 때는 인터넷이 되는 PC에서 데이터 파일만 받아 전달하면 됩니다. 공공기관의 망분리 환경을 고려한 배포 방식입니다.
어떤 법령이 들어가 있나요?
국가법령정보센터의 현행 법률·대통령령·법률시행령 등 약 5,600여 개 법령, 20만여 개 조문이며 호·항·목까지 복원했습니다. 자치법규는 설정 › 자치법규에서 문서 파일을 추가하면 ‘자치’ 표시와 함께 조회됩니다.
데이터는 어떻게 최신화되나요?
매일 새벽 3시(한국시간) 개정분만 델타로 배포하고 모든 파일을 SHA-256으로 검증합니다. 갱신 체인에 틈이 있으면 자동으로 전체 스냅샷을 받아 복구합니다. 배포는 GitHub와 이 서버의 자체 미러를 모두 사용해 한쪽이 막혀도 최신화가 이어집니다.
복사하지 않고 직접 검색할 수도 있나요?
네, Ctrl+Alt+L이면 어떤 창에서든 조회 창이 뜹니다. “민법 750”처럼 대략적으로 입력해도 찾습니다.
지우려면 어떻게 하나요?
프로그램 폴더와 설정·데이터(AppData › immediatelylaw)만 사용합니다. 프로그램 추가/제거나 폴더 삭제 후 위 폴더를 지우면 흔적 없이 사라집니다.
