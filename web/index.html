03 / GOOD TO KNOW

궁금한 점이
남아 있다면.

정말 무료인가요?

네. 즉시로는 MIT 라이선스로 공개된 무료 오픈소스 프로그램입니다. 소스코드를 확인하고 수정·재배포할 수 있습니다. 재배포 시 라이선스와 원작자 표시를 유지해 주세요.

인터넷이 없는 업무용 PC에서도 쓸 수 있나요?

오프라인 패키지를 인터넷이 가능한 다른 PC에서 내려받아 전달하면 됩니다. 압축을 풀고 ImmediatelyLaw.exe를 실행하면 동봉된 데이터로 조회합니다. 데이터 최신화에는 인터넷 연결 또는 별도 전달이 필요합니다.

최신 법령인지 어떻게 확인하나요?

배포 법령 데이터는 매일 자동 갱신되며 앱은 시작 시와 주기적으로 새 데이터를 확인합니다. 온라인 검증 결과는 앱의 현행·확인·오프라인 배지로 구분됩니다. 법령의 효력 판단은 국가법령정보센터 공식 원문을 기준으로 해 주세요.

API 키가 꼭 필요한가요?

아니요. 기본 조회는 API 키 없이 동작합니다. 국가법령정보 공동활용 OC 인증키를 등록하면 미보유 법령 수집 및 실시간 검증 등 추가 기능을 사용할 수 있습니다.

우리 기관의 조례나 규정도 등록할 수 있나요?

앱의 설정 → 자치법규에서 파일을 추가하세요. HWP, HWPX, DOC, DOCX, PDF, RTF, TXT, MD 형식을 지원하며 등록 자료는 자치 배지로 구분됩니다.
